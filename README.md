# Purposeful Launch

Create a premium, professional, elegant ONE-PAGE STATIC BOOK LANDING PAGE for the book:

BOOK TITLE:
Lead with Purpose

SUBTITLE:
A Practical Guide to Building a Life of Purpose, Growth, and Impact

AUTHOR:
Daniel Carter

Use the uploaded book cover and author image as the main visual references.

IMPORTANT:
This should NOT look like a complicated SaaS website, online store, dashboard, or generic template.
It should feel like a sophisticated author/book promotional website designed specifically around this book.

DESIGN DIRECTION
The visual identity should be inspired directly by the book cover:

Primary colors:
- Deep charcoal / near black: #11171A
- Soft ivory / warm white: #F6F1E8
- Warm gold / amber: #E9A93F
- Dark muted slate: #252E32

Optional subtle accent:
- Deep forest green inspired by the author promotional image, used very sparingly.

Overall mood:
- Premium
- Inspirational
- Mature
- Purpose-driven
- Sophisticated
- Calm
- Trustworthy
- Leadership-focused
- Editorial rather than corporate

Avoid:
- Bright random colors
- Heavy gradients
- Glassmorphism
- Neon effects
- Excessive animation
- Overly rounded cards
- Cartoon-style icons
- Generic stock imagery
- Cluttered layouts

TYPOGRAPHY
Use an elegant editorial serif font for major headings, similar to the typography on the book cover.

Recommended style:
- Headings: Cormorant Garamond / Playfair Display / DM Serif Display
- Body and buttons: Inter / Manrope / Source Sans 3

Headlines should feel like a premium published book.

RESPONSIVE DESIGN

Desktop:
Elegant wide editorial layout.

Tablet:
Maintain strong spacing and hierarchy.

Mobile:
Stack all two-column sections vertically.
Book image should appear below hero copy.
Keep large title readable.
Buttons should be easy to tap.
No horizontal overflow.
Do not make text excessively large.

ANIMATION

Only very subtle premium motion:
- gentle fade-up on scroll
- very small image reveal
- button hover
- subtle nav transition

No parallax overload.
No dramatic floating effects.
No bouncing animations.


IMAGE RULES

Use the actual uploaded book cover.
Do not recreate or modify its typography.
Do not replace it with an AI-generated book.
Do not distort the cover.

Use the uploaded Daniel Carter image as the author reference.
Keep his appearance natural and professional.

If any background visuals are required, they should only support the book theme:
- sunrise
- distant mountains
- winding path
- subtle light
- editorial texture

Do not use unrelated generic office stock photography.


TECHNICAL REQUIREMENTS

Build it as a normal lightweight static landing page.

Use:
- React
- clean responsive CSS
- semantic HTML
- reusable components

No backend is needed.
No login.
No dashboard.
No unnecessary forms.
No complex dependencies.

Navigation links should smoothly scroll to relevant page sections.

Make the final result feel like a professionally designed landing page from a premium leadership / personal development book launch.
